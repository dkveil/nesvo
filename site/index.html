What it does

  • Conversation-first sessions

    Each session is a focused conversation with Claude Code or Codex in a project folder, with its history stored on the computer that runs it.

  • Explicit permissions

    Pick the permission mode the provider supports for every session. Nothing widens silently, and requests the app cannot ask about are refused visibly.

  • One inbox for decisions

    Approve operations, accept or correct saved results and decide on proposed workers from a single list.

  • Workers, workflows and automations

    See every worker a session proposes, assign saved workflows and schedule automations that report back to the inbox.

  • Files, skills and pull requests

    Browse session files, invoke skills with / and review GitHub pull requests without leaving the app.

  • Local, SSH and mobile

    Run sessions on this computer or on a server over SSH, and follow them from the mobile companion, now in preview.

How it works

  1. 1

    Install the app

    Download Nesvo for Windows or macOS and open it.

  2. 2

    Sign in as usual

    Sign in to Claude Code and/or Codex in your terminal. Nesvo uses that login and never asks for an API key.

  3. 3

    Start a session

    Choose a folder, pick a permission mode and send your first message.

Requirements

System
Windows 10 or 11 (x64), or macOS 12 or later
Provider
Claude Code or Codex CLI, installed and signed in
Optional
GitHub CLI, signed in, for pull requests

First launch

Builds are not code-signed yet and do not update automatically. Your system will ask for confirmation the first time. Download new versions from this page.

Windows

If you see Windows protected your PC, select More info, then Run anyway.

macOS

If macOS says the app is damaged or from an unidentified developer, right-click Nesvo in Applications and choose Open. Or run this in Terminal: 

xattr -dr com.apple.quarantine /Applications/Nesvo.app
